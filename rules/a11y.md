# Accessibility Rules

## Semantic HTML
**Correct elements:** `<button>`, `<nav>`, `<main>`
**Heading hierarchy:** h1→h2→h3
**Landmarks:** Use semantic landmarks
**Form labels:** All form inputs labeled

## ARIA
**Only when necessary:** Use only when semantic HTML insufficient
**Labels:** `aria-label` for icons, `aria-describedby` for help
**Dynamic:** `aria-live` for dynamic content

## Keyboard Navigation
**All interactive accessible:** Tab to all interactive elements
**Visible focus:** Clear focus indicators
**Logical tab order:** Natural reading flow
**Skip links:** Skip to main content
**Modals:** Escape closes modals

## Visual Requirements
**WCAG AA contrast:** 4.5:1 text, 3:1 UI components
**Don't rely on color alone:** Use patterns, text, icons
**Text resize:** Support 200% text resize
**No flashing:** Avoid content that flashes

## Alt Text
**Meaningful images:** Describe content and function
**Decorative images:** Empty alt attribute
**Video/Audio:** Provide captions and transcripts

## WCAG Levels
**A:** Minimum (legal requirement in many jurisdictions)
**AA:** Target (industry standard)
**AAA:** Ideal (gold standard)

## Testing Tools
**Browser extensions:** axe DevTools
**Automated:** Lighthouse, Pa11y CI/CD
**Manual:** Keyboard-only navigation
**Screen readers:** NVDA (Windows), JAWS (Windows), VoiceOver (macOS/iOS)
